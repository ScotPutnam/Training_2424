## Array Lists

== Style 1 ==
- Declare then allocate style

int[] scores;
scores = new int[5];

== Style 2 ==
- Declare and allocate on one line
int[] scores = new int[5];

== Style 3 ==
- Declare, allocate, and initialize

int[] scores = new int[5]{1, 2, 3, 4, 5};

== Style 4 ==
- Array initializer shorthand, implicit size and type declaration
int[] scores = {1, 2, 3, 4, 5};
- Only valid for declaring arrays not reassigning

== Convention ==
int[] a,b
- type grouped with closed braces is most readable

== Length property ==
- Arrays have fixed length at creation, .length accesses this fixed length field
- to resize an array you must create a new array and copy

== Default Values ==
- byte, short, int: 0
- long:             0L
- float:            0.0f
- double:           0.0
- char:             '\u0000' (null char)
- boolean:          false
- Reference type:   null    -> reference type is any object

int[] nums = new int[3] -> nums = [0,0,0]
boolean[] flags = new boolean[3] = [false,false,false]
String[] names = new String[3] = [null, null, null]

== Zero based indexing ==
You know arrays start at index 0, avoid off by 1, use < operator in iterator < arr.length to avoid off by 1

or

for (int val: iterable){
    System.out.println("val");
}

== Arrays are Reference Type ==
- Array variable holds reference to the array

-- Aliasing --
int[] a = new int[3];
int[] b = a
- B copies the reference to A, mutating B mutates A

-- Array as parameters --

- Arrays passed as parameters to functions will be mutated by the functions operations
- Pass array copy to avoid function mutation

-- == equality on reference --
double equals sign compares reference value, not content value
use .equals() method to compare array content equality

== Iterating arrays ==
String[] names = {"Bob", "Alice", "Theresa"};

- try to avoid index based, alright if needed though error prone
// index based
for (int i = 0; i < names.length; i++){
    System.out.println(names[i]);
}

- usually the cleanest solution
// enhanced for-loop
for (String name: names){
    System.out.println(name);
}

// reverse iteration

for (int i = names.length - 1; i > 0; i--){
    System.out.println(names[i]);
}

== Array Utilities ==
import java.util.Arrays;

- Arrays.toString(arr)
- Arrays.deepToString(arr)
- Arrays.sort(arr)
- Arrays.sort(arr, to, from)
- Arrays.binarySearch(arr, key)
- Arrays.fill(arr, value)
- Arrays.copyOf(arr)
- Arrays.copyOfRange(arr, from, to)
- Arrays.equal(a, b)
- Arrays.stream(arr)    -> enables functional operations (filter, reduce, map)
